# Camera Drill

設定を動かすと、写真がどう変わるかがその場で見える、駆け出しカメラマン向けのカメラ学習シミュレーター。

- **講座モード**: 露出・ブレ・ノイズ・ボケ・画角・撮影モード・Log・収差を、説明 → 体験 → 課題の順で学ぶ
- **シミュレーターモード**: F値・シャッタースピード・ISO・レンズ・ピントを自由に操作して撮影・比較する

仕様は [SPEC.md](SPEC.md) を参照。

## 開発

```bash
npm install
npm run dev
```

```bash
npm test
```

```bash
npm run build
```

## 構成

| ディレクトリ | 内容 |
|---|---|
| `src/physics/` | 露出・錯乱円・画角・ノイズ・手ブレ・撮影モード・Log・収差の計算（純粋関数＋テスト） |
| `src/render/` | 描画エンジン（HDR描画 → ブレ → ボケ → 露出・ノイズ → 現像）とシェーダー |
| `src/scenes/` | シーン（アトリエ、回転台、彫刻庭園、スタジオ）。光源は物理単位（lx, cd, cd/m²） |
| `src/camera/` | レンズの定義 |
| `src/store/` | 状態（カメラのリグ、設定、進捗）と学習用の指標の計算 |
| `src/lessons/` | 講座の内容と課題の判定 |
| `src/ui/` | 画面 |
